# Smart Home Dashboard 2.2.0

## Multiple administrators

- Replaced the original single shared administrator PIN with named administrator accounts.
- Every new administrator must enter a name and choose a 4–12 digit PIN.
- Existing single-PIN installations migrate automatically to an administrator named **Administrator**.
- Added administrator account management in System Settings:
  - Add another administrator
  - Change your own PIN
  - Reset another administrator's PIN
- Administrator PINs continue to be stored as salted scrypt hashes, not plaintext.

## More themes

Added four new dashboard themes:

- Ocean
- Forest
- Violet
- Slate

Existing Midnight, Graphite, High Contrast and Warm themes remain available.

## Smarter release notes

- The Dashboard status card on Home is now clickable and opens release notes.
- If an update is available, it shows release notes for the available version.
- If the dashboard is up to date, it shows release notes for the currently installed version.
- Settings → Updates → View Release Notes uses the same behavior.
