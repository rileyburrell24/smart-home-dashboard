# Smart Home Dashboard 2.1.2

## Dashboard navigation

- Added a permanent left-side navigation rail on larger screens.
- Added Home, Rooms, Heating and Cameras sections.
- Only one main dashboard section is shown at a time, greatly reducing vertical scrolling.
- The selected dashboard section is remembered on the device.
- On smaller screens the left rail automatically becomes a compact horizontal navigation bar.

## Home overview

- Added a compact Home overview with shortcuts to Rooms, Heating and Cameras.
- Home shows useful live summaries such as room activity, heating temperatures and camera count.

## Release notes

- Added a dedicated **View Release Notes** button in Settings → Updates.
- Release notes can now be opened for the currently installed version even when no update is available.
- Installed-version release notes continue to come from GitHub.

## Layout refinements

- Main section cards use a more compact grid to reduce scrolling.
- Existing responsive text and icon scaling remains enabled.
