# Smart Home Dashboard 2.3.0

## Configurable Home Overview

- Added an administrator-only Home Overview editor under **Settings → Dashboard Layout**.
- Administrators can show or hide Home widgets and change their order.
- Available Home widgets include:
  - Lights summary
  - Heating summary
  - Cameras summary
  - Dashboard/update status
  - A live camera widget for every camera discovered in Home Assistant
- Live camera widgets can be opened into the existing full-screen camera view.
- Existing installations keep the current four Home summary widgets by default.

## Update and error display fix

- Long update/build errors now stay inside the update panel.
- Technical error text wraps instead of overflowing outside the card.
- Large error messages become scrollable inside their own area.
- The progress percentage and phase labels also wrap safely on smaller displays.

## Persistence

- Home Overview choices are saved in the existing dashboard configuration and are preserved through dashboard updates.

## Context-aware release-notes return button

- Release notes opened from the Home dashboard now show **Return to Dashboard**.
- Release notes opened from Settings continue to show **Return to Settings**.
- The return action takes you back to the screen you opened the notes from.
