# Smart Home Dashboard 2.1.4

## Release notes fix

- Fixed **View Release Notes** in Settings → Updates.
- The release-notes screen now opens immediately and then loads the currently installed version from GitHub.
- Errors loading release notes are shown inside the full-screen release-notes view instead of silently doing nothing.

## Home overview

- Reworked the Home tab so it is no longer a duplicate of the left-side navigation.
- Home now shows a compact overview of the house:
  - Lights on / total lights
  - Current and target heating temperature
  - Camera count
  - Dashboard update status
- Rooms, Heating and Cameras remain available from the permanent left-side navigation.

## Compact header

- Reduced the height of the Smart Home header on all display sizes.
- Reduced heading, clock, weather and action-button sizes.
- The header remains responsive but now uses much less vertical space on wall panels and tablets.
