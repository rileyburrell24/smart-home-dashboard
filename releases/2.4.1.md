# Smart Home Dashboard 2.4.1

## First verified OTA feature test

Version 2.4.1 is intentionally a feature-heavy but updater-stable release designed to test the new 2.4.0 verified update engine.

## Update History

- Added an Update History section under Settings → Updates.
- Records successful updates, failed pre-restart updates and automatic rollbacks.
- Shows the previous version, target version, result, time and a short status message.

## System Diagnostics

- Added System Diagnostics under Settings → System.
- Shows dashboard version, Home Assistant connection, Docker availability, rollback availability and update-channel status.
- Added Copy Diagnostics.
- The diagnostics report does not include administrator PINs, passwords or the Home Assistant token.

## Update package information

- Settings → Updates now displays the available version, publish time, package-part count and SHA-256 checksum.
- Added a visible Rollback Status section showing whether a previous working Docker image is available.

## Home overview customisation

- Home widgets now support Small, Medium, Wide and Full Width sizes.
- Existing Up and Down controls remain available for accessible keyboard/screen-reader-friendly ordering.
- Added dashboard density choices: Compact, Comfortable and Large Touch Targets.
- Added header visibility controls for Date, Time, Weather, All On, All Off and the update indicator.
- Added Reset Customisation to Defaults.

## Accessibility improvements

- Font and text-size changes now preview immediately before saving.
- Added Wall Panel Large and Maximum text-size options.
- Added Save Accessibility and Reset Accessibility to Defaults.
- Themes remain in Accessibility with the existing eight theme choices.

## Runtime cleanup

- Corrected the 2.4.x normal-file migration so the server now serves the normal `public/index.html`, `public/app.js` and `public/styles.css` files directly rather than referring to the retired compressed payload files.
