# Smart Home Dashboard 2.2.1

## Updater packaging fix

- Fixed OTA updates failing during the Docker rebuild because `server.patch.b64` was referenced by the Dockerfile but was no longer shipped.
- Removed the obsolete `server.patch.b64` Docker copy step.
- The Docker image now copies the required `server.payload.b64` runtime payload.
- Bumped the running dashboard runtime to 2.2.1 so update completion is detected correctly after restart.
- Home Assistant credentials, administrator accounts, themes and dashboard settings are preserved.
