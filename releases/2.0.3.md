# Smart Home Dashboard 2.0.3

## Improved update experience

- Check for Updates now opens a full-screen update screen immediately.
- The screen displays **Checking for updates…** while GitHub is being checked.
- If no update is available, it shows **You’re up to date** and a **Return to Dashboard** button.
- If an update is available, it shows the new version and loads release notes directly from GitHub.
- Update Now, Update Later and Schedule Update remain available.

## Automatic Updates

- Automatic Updates are now **enabled by default** for new installations.
- Automatic Updates can be turned on or off in the Updates section of Administrator Settings.
- When Automatic Updates are enabled, a preferred local installation time can be selected.
- When a newer GitHub version is detected, the dashboard schedules it for the selected time.
- Existing credentials, administrator PIN and dashboard settings are preserved.
