# Smart Home Dashboard 2.1.1

## Update detection reliability

- Fixed `GitHub API returned 403` when checking for updates.
- Update detection no longer relies on the GitHub REST API.
- The dashboard uses `git ls-remote` to read the latest `main` branch commit.
- `package.json` is downloaded by immutable commit SHA.
- This avoids GitHub API rate limits and stale branch-cache responses.

## Main dashboard update notice

- Added a compact **Update available** control to the main Smart Home header.
- It appears only when a newer dashboard version is available.
- It shows the available version number.
- Selecting it opens the full-screen update flow and release notes.
- The dashboard checks periodically in the background.
