# Smart Home Dashboard 2.3.4

## OTA updater image identification fix

- Fixed updates failing at around 92% with **Could not identify the newly built dashboard image**.
- The Docker Compose service now uses the deterministic image name `smart-home-dashboard:latest`.
- The updater no longer relies on `docker compose images -q` to discover the image ID.
- After building, the updater verifies the known image tag exists and then hands the restart to the update helper.
- Existing Home Assistant credentials, administrators, themes and dashboard settings remain preserved.
