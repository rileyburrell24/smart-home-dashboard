# Smart Home Dashboard 2.1.3

## Complete update flow

- Selecting an update from the main dashboard now leads directly into the install flow.
- If Administrator Settings is not already unlocked, **Download and Install Update** automatically asks for the administrator PIN.
- Fixed the update details screen so an available update always includes an install button.

## Download and installation progress

- Update installation now stays on the full-screen update page until completion.
- Added a real download progress bar and percentage when GitHub provides download size information.
- Added clear update stages:
  - Downloading
  - Installing
  - Restarting
  - Complete
- The update page remains visible while the dashboard container rebuilds and restarts.
- Once the updated dashboard returns online, the page automatically refreshes to the new version.

## Reliability

- Update progress is persisted locally so the new container can report completion after restarting.
- Existing Home Assistant credentials, administrator PIN, dashboard layout and theme settings remain preserved.
