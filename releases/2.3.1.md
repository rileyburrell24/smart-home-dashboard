# Smart Home Dashboard 2.3.1

## Reliable over-the-air container replacement

- Fixed OTA updates failing with **container name `/smart-home-dashboard` is already in use**.
- Updates now build the new Docker image while the current dashboard remains online.
- After the build succeeds, a short-lived helper container safely replaces the running dashboard.
- The browser continues showing **Restarting dashboard…** while the old container is replaced and the new one comes online.
- Stale updater helper containers from interrupted attempts are cleaned up automatically.

## Cleaner Administrator settings

- Added a dedicated **Administrator** category in the Settings sidebar.
- Removed administrator management from the main System page.
- Administrator account management now uses cleaner, wider cards.
- On smaller tablets, Add Administrator, Change My PIN and Reset PIN stack vertically instead of being squeezed into narrow columns.

## Text containment

- Button text now wraps inside buttons throughout the dashboard.
- Long labels automatically use the available width instead of overflowing.
- Settings navigation, layout controls, themes and action buttons are included in the fix.
- Inputs and selectors also stay within their cards on narrow screens.
