# Smart Home Dashboard 2.1.0

## Settings redesign

- Replaced the oversized Settings banner with a compact single top bar.
- Settings now shows **Settings** on the left and **Close** on the top right.
- Added a two-column settings layout with categories on the left and the selected page on the right.
- Added dedicated categories for System, Dashboard Layout, Updates and Themes.
- On smaller screens, category navigation automatically becomes a compact horizontal layout.

## Responsive interface

- Typography scales dynamically with screen size and resolution.
- Navigation icons and controls scale with the display.
- Layout adapts for wall panels, tablets and smaller screens.

## Themes

- Added Midnight, Graphite, High Contrast and Warm themes.
- Theme choice is saved and persists after restart.

## Updates

- Update controls now live in their own Updates category.
- Automatic Updates and preferred installation time remain available.
- GitHub update checking and release notes continue to work.
