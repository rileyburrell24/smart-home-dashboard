# Smart Home Dashboard 2.0.2

## Updater bootstrap fix

- Fixed the error: `Dashboard host directory is unavailable: /DATA/AppData/smarthome-dashboard`.
- The updater now accesses dashboard files through the container bind mount at `/host-dashboard`.
- Docker Compose still receives the real Raspberry Pi host path `/DATA/AppData/smarthome-dashboard`.
- Future GitHub updates can replace application files, rebuild the container and restart the dashboard correctly.
- `.env`, administrator PIN data and saved dashboard settings remain preserved.

## Update manager

- Automatic Updates remains available.
- Check for Updates still opens the full-screen release-notes view.
- Update Now, Update Later and Schedule Update remain available.

## Important

Version 2.0.0 cannot self-install this fix because its updater fails before it can copy replacement files. Install 2.0.2 manually once; future updates should then install through the dashboard.
