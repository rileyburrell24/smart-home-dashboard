# Smart Home Dashboard 2.3.3

## Administrator account deletion

- Added **Delete** controls for individual administrator accounts.
- The administrator currently signed in cannot delete their own account individually; sign in as another administrator or use Delete All Administrators.
- Added **Delete All Administrators** with a confirmation prompt.
- Deleting all administrators clears administrator sessions and returns the dashboard to administrator setup mode.

## Clearer Administrator settings

- Reorganised Admiinistrator settings into clearly labelled sections:
  - Administrator Sign In
  - Administrator Accounts
  - Add Administrator
  - PIN Management
  - Delete Administrators
- Administrator accounts now appear in clean rows with clear status and delete controls.

## Themes restored

- Fixed malformed Settings markup that caused the Themes page to be nested inside the Administrator page and therefore remain hidden.
- Restored all eight themes:
  - Midnight
  - Graphite
  - High Contrast
  - Warm
  - Ocean
  - Forest
  - Violet
  - Slate
- Theme cards are now explicitly rendered in their own Settings page.
