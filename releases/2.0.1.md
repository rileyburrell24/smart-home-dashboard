# Smart Home Dashboard 2.0.1

## Update management

- Added **Automatic Updates**, which can be enabled or disabled from Administrator Settings.
- Automatic updates check GitHub every 15 minutes and install newer dashboard versions automatically when enabled.
- Added a full-screen update details screen when a newer version is found.
- Release notes are downloaded from GitHub from `releases/<version>.md`.
- Added **Update Now**, **Update Later**, and **Schedule Update** options.
- Scheduled updates are saved on the Raspberry Pi and survive dashboard/container restarts.
- Scheduled updates run at the selected local date and time.
- Update status shows the installed version, latest GitHub version, automatic-update state, and scheduled install time.
- Existing `.env`, administrator PIN data, room layout and dashboard settings remain preserved during updates.

## Safety and reliability

- Update installation still uses the existing validated GitHub source package flow.
- Automatic Updates can only be changed while Administrator Settings is unlocked.
- Scheduled updates can be cancelled from the update screen.
- Failed GitHub checks or installs are shown in the dashboard rather than silently ignored.
